<p align="center">

## 왜 만들었나

학교·회사·PC방 같은 **외부 PC**에서 내 계정으로 유튜브를 켜면, 홈 화면이나 사이드바에 내 구독 채널이 그대로 드러나서 민망할 때가 있습니다.
구독을 끊기는 싫고, 잠깐 쓰는 동안만 안 보였으면 좋겠다 — 그 용도입니다.

- 구독을 **취소하지 않습니다.** 내 유튜브 계정에는 아무것도 바꾸지 않습니다.
- 확장 프로그램을 설치한 **그 브라우저 화면에서만** 가립니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 구독 채널 목록 | 설정창을 열면 로그인한 유튜브 계정의 구독 채널을 자동으로 불러옵니다 |
| 채널별 보임 / 숨김 | 채널 옆 스위치를 끄면 그 채널의 영상이 숨겨지고, 다시 켜면 보입니다 |
| 전체 차단 / 전체 해제 | 버튼 하나로 모든 구독 채널을 숨기거나 다시 보이게 합니다 |
| 키워드 차단 | 제목·채널명에 키워드가 들어간 영상을 숨깁니다 (구독하지 않은 채널도 포함) |
| 크롬을 닫으면 자동 삭제 | 기본으로 켜져 있습니다. 목록을 메모리에만 두고, 크롬을 닫으면 사라집니다 |
| 지금 모두 지우기 | 저장된 목록을 즉시 삭제합니다 |

**숨기는 곳:** 홈 · 구독 피드 · 검색 결과 · 시청 화면 오른쪽 추천 · Shorts · 왼쪽 사이드바 구독 목록 · 커뮤니티 게시물 · 알림

## 개인정보

- 구독 목록·차단 목록·키워드는 **그 PC의 브라우저 안에만** 저장됩니다.
- 어떤 서버로도 전송하지 않으며, 크롬 계정 동기화(`chrome.storage.sync`)도 쓰지 않습니다. 다른 PC로 넘어가지 않습니다.
- 이 저장소에는 코드만 있습니다. 누구의 차단 목록도 저장소에 올라가지 않습니다.
- API 키나 구글 로그인 권한을 요구하지 않습니다. 이미 로그인된 유튜브 화면에서 구독 목록을 읽어 올 뿐입니다.

## 설치 방법

> 크롬 웹스토어에 올라가 있지 않으므로 **개발자 모드**로 설치합니다. (엣지·웨일 등 크로미움 기반 브라우저도 같은 방법으로 설치할 수 있습니다.)

### 1. 파일 내려받기
1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼을 누릅니다.
2. 맨 아래 **Download ZIP**을 누릅니다.
3. 내려받은 `yt-sub-hider-main.zip`의 **압축을 풉니다.**
   - 압축을 푼 폴더 안에 `manifest.json` 파일이 바로 보여야 합니다.

### 2. 크롬에 설치하기
1. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
2. 화면 **오른쪽 위**의 **개발자 모드** 스위치를 켭니다.
3. 왼쪽 위에 생긴 **압축해제된 확장 프로그램 로드** 버튼을 누릅니다.
4. 압축을 푼 폴더(`manifest.json`이 들어 있는 폴더)를 선택하고 **폴더 선택**을 누릅니다.
5. 목록에 **구독 가리개**가 나타나면 설치 완료입니다.

### 3. 툴바에 고정하기 (권장)
1. 주소창 오른쪽의 **퍼즐 모양 아이콘**을 누릅니다.
2. **구독 가리개** 옆의 **핀** 아이콘을 누릅니다.
3. 툴바에 눈가리개 아이콘이 고정됩니다.

> **설치가 안 되나요?**
> - 개발자 모드 스위치가 회색으로 잠겨 있다면, 그 PC는 관리자 정책으로 확장 설치가 막혀 있는 상태라 사용할 수 없습니다.
> - "매니페스트 파일이 없습니다" 오류가 나면, 한 단계 안쪽 폴더(`manifest.json`이 보이는 폴더)를 선택하세요.
> - 크롬을 켤 때 "개발자 모드 확장 프로그램 사용 중지" 경고가 뜰 수 있습니다. **닫기**를 누르면 됩니다.

## 사용 방법

### 1. 구독 목록 불러오기
1. 크롬에서 [youtube.com](https://www.youtube.com)에 **로그인**합니다.
2. 툴바의 **눈가리개 아이콘**을 누르면 설정창이 새 탭으로 열립니다.
3. 처음 열면 구독 목록을 **자동으로** 불러옵니다. (구독이 많으면 몇 초 걸릴 수 있습니다.)
   - 유튜브 탭이 열려 있지 않으면, 백그라운드에서 유튜브 탭을 잠깐 열었다가 자동으로 닫습니다.
   - 다시 불러오려면 오른쪽 위 **구독 목록 새로고침**을 누릅니다.

### 2. 채널 숨기기 / 다시 보이기
- 채널 옆 스위치가 **초록색(켜짐) = 보임**, **회색(꺼짐) = 숨김**입니다.
- 스위치를 끄면 열려 있는 유튜브 탭에서 **바로** 사라집니다. 새로고침할 필요가 없습니다.
- 다시 켜면 바로 다시 보입니다.
- 위쪽 **검색창**에 채널 이름이나 `@핸들`을 입력해 빠르게 찾을 수 있습니다.

### 3. 한 번에 처리하기
- **전체 차단**: 모든 구독 채널을 숨깁니다. (한 번 더 확인합니다)
- **전체 해제**: 숨긴 채널을 모두 다시 보이게 합니다.

### 4. 키워드 차단
1. **키워드 차단** 칸에 단어를 입력하고 **추가**를 누릅니다. (예: `ASMR`)
2. 제목이나 채널명에 그 단어가 들어간 영상이 숨겨집니다. 대소문자는 구분하지 않습니다.
3. 키워드 옆 **×**를 누르면 삭제됩니다.

> 유튜브 추천 알고리즘 자체를 바꾸지는 못합니다. 비슷한 영상이 추천되는 것은 막을 수 없지만, 키워드로 **화면에 보이지 않게** 할 수는 있습니다.

### 5. 다 쓰고 나서 (외부 PC)
흔적을 남기지 않으려면 아래 중 하나를 하세요.

| 방법 | 결과 |
|---|---|
| **크롬을 완전히 닫기** | "크롬을 닫으면 자동 삭제"가 켜져 있으면(기본값) 목록이 사라집니다 |
| 설정창의 **모두 지우기** | 목록을 즉시 삭제합니다 |
| `chrome://extensions`에서 **삭제** | 확장 프로그램과 저장된 목록이 모두 지워집니다 (가장 확실) |

내려받은 ZIP 파일과 압축 푼 폴더도 함께 지우면 깔끔합니다.

### 6. 설정 저장
- 스위치·키워드는 **누르는 즉시 저장**되고 유튜브에 바로 적용됩니다.
- 오른쪽 위 **설정 저장** 버튼을 누르면 저장이 끝난 것을 확인한 뒤 **설정창 탭만** 닫힙니다.

## 업데이트 방법 (지우지 않고 덮어쓰기)

설정창을 열면 자동으로 새 버전을 확인합니다. 새 버전이 있으면 설정창 맨 위에 파란색 안내가 뜹니다.

1. 설치 폴더(`manifest.json`이 있는 폴더) 안의 **`update.bat`** 을 더블클릭합니다.
   - GitHub에서 최신 버전을 내려받아 **같은 폴더에 덮어씁니다.** 확장 프로그램을 지울 필요가 없습니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (인터넷에서 받은 .bat 파일에 Windows가 띄우는 기본 경고입니다)
2. "업데이트 파일을 덮어썼습니다"가 나오면 아무 키나 눌러 창을 닫습니다.
3. 설정창 맨 아래 **다시 불러오기**를 누릅니다. (또는 `chrome://extensions`에서 구독 가리개의 **↻** 버튼)

> - 폴더 위치가 그대로이므로 확장 프로그램 ID와 설정이 유지됩니다.
> - 단, **"크롬을 닫으면 자동 삭제"가 켜져 있으면** 다시 불러올 때 숨김 목록이 초기화됩니다.
> - 업데이트 확인은 GitHub의 `manifest.json`에서 **버전 번호만** 읽어 옵니다. 아무 정보도 보내지 않습니다.
> - 크롬이 알아서 업데이트하는 자동 업데이트는 웹스토어 등록 시에만 가능해서, 이 방식을 사용합니다.

## 계정 관련 Q&A

**Q. 크롬에 로그인한 계정 기준인가요?**
아니요. **그 브라우저에서 유튜브에 로그인되어 있는 계정** 기준입니다. 크롬 프로필에 로그인하지 않아도, 유튜브에만 로그인되어 있으면 그 계정의 구독 목록을 불러옵니다.

**Q. 유튜브 계정을 바꾸면요?**
- 구독 목록은 **구독 목록 새로고침**을 눌렀을 때 현재 유튜브 계정 기준으로 다시 불러옵니다.
- 숨김 설정은 유튜브 계정별이 아니라 **이 브라우저에 하나만** 저장됩니다. 계정을 바꿔도 이전에 숨긴 채널은 계속 숨겨집니다. 필요하면 **전체 해제**나 **모두 지우기**를 누르세요.

**Q. 다른 PC에서도 설정이 유지되나요?**
아니요. 일부러 그렇게 만들었습니다. 설치할 때마다 빈 상태에서 시작하고, 설정은 그 PC 밖으로 나가지 않습니다.

**Q. 내 구독이 취소되거나 유튜브 계정 설정이 바뀌나요?**
아니요. 화면에서 가리기만 하고 계정에는 아무것도 바꾸지 않습니다.

## 한계

- 이 확장을 설치한 브라우저에서만 동작합니다. 모바일 앱·TV·다른 브라우저에는 적용되지 않습니다.
- 채널 페이지나 영상 링크로 **직접** 들어가면 보입니다.
- 채널 정보가 표시되지 않는 Shorts 카드는 **키워드로만** 숨길 수 있습니다.
- 유튜브가 화면 구조를 바꾸면 일부가 다시 보일 수 있습니다. 이때는 `content.js` 맨 위의 `CARD_SELECTORS` 목록을 고치면 됩니다.

```

content.js      유튜브 화면에서 영상 숨기기 + 구독 목록 읽기

options.css     설정창 스타일

CHANGELOG.md    버전별 변경 내역
icons/          아이콘
```
