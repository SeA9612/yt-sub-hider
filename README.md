# 구독 가리개

유튜브 구독은 그대로 유지하면서, 선택한 채널의 영상을 유튜브 화면에서 숨기는 크롬 확장 프로그램입니다.
외부 PC에서 유튜브를 쓸 때 민망한 상황을 막기 위해 만들었습니다.

## 기능
- 내 구독 채널 목록 표시, 채널별 보임/숨김 스위치
- 전체 차단 / 전체 해제
- 키워드 차단 (제목·채널명에 키워드가 들어간 영상도 숨김)
- 크롬을 닫으면 자동 삭제 (기본 켜짐)
- 모든 정보는 그 PC의 브라우저 안에만 저장되며 외부로 전송되지 않음

숨기는 곳: 홈, 구독 피드, 검색 결과, 시청 화면 추천, Shorts, 왼쪽 사이드바 구독 목록, 커뮤니티 게시물, 알림

## 설치 (개발자 모드)
1. 이 저장소를 ZIP으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 폴더를 선택합니다.

## 사용
1. 유튜브에 로그인합니다.
2. 툴바의 확장 프로그램 아이콘을 누르면 설정창이 열리고 구독 목록을 자동으로 불러옵니다.
3. 숨길 채널의 스위치를 끕니다. 열려 있는 유튜브 탭에 바로 적용됩니다.
4. 다 쓰고 나면 `chrome://extensions`에서 **삭제**합니다. 저장된 목록도 함께 지워집니다.

## 한계
- 이 확장을 설치한 크롬에서만 동작합니다 (모바일 앱·TV에는 적용되지 않음).
- 채널 페이지나 영상 링크로 직접 들어가면 보입니다.
- 채널 정보가 없는 Shorts 카드는 키워드로만 숨길 수 있습니다.
- 유튜브가 화면 구조를 바꾸면 `content.js` 맨 위의 `CARD_SELECTORS` 목록을 고쳐야 할 수 있습니다.
